설정에서 프로그램 버전을 확인하실 수 있습니다. 두 버전의 패치는 서로 호환되지 않습니다.

## 설치

1. 해당 버전의 ZIP을 다운로드하고 새 폴더에 완전히 압축 해제합니다.
2. `install.bat`를 실행하고 관리자 권한을 허용합니다. Python 3가 필요합니다.
3. 완료 문구를 확인하고 AJAZZ의 언어를 **English(영어)**로 선택합니다.

영어 테이블을 한국어로 교체하는 방식입니다. 업데이트 후 프로그램 버전이 바뀌면 해당 버전용 패치가 필요합니다.

## 3.10.200.0420 변경 사항

- 제공된 원본 EXE/DLL에 맞춘 전용 변경분 패치입니다.
- 영어 비압축 테이블 18개와 압축 테이블 3개를 처리합니다.
- 긴 안내문은 의미를 유지해 간결하게 번역했습니다.
- 필수 파일 전체를 사전 검증하며 다른 버전 또는 기존 변경 파일이면 중단합니다.
- 이미 적용된 파일을 구분하고 저장 결과의 SHA256을 검증합니다.
- 백업은 `.ko-backup-3.10.200.0420`으로 별도 보관합니다.
- 플러그인 폴더의 `ko.json`이 존재하는 경우 영어 파일에 적용합니다.
- 바이너리 크기, 압축 해제, JSON 구문, 패치 재구성 SHA256을 확인했습니다. Windows 앱 실행 및 실제 장치 동작은 검증하지 못했습니다.

복원은 관리자 터미널에서 해당 버전 폴더의 `python revert_patch.py`를 실행합니다.

## 기존 3.10.191.0421 패치

기존 파일은 `versions/3.10.191.0421`에 그대로 보존했습니다.
**저장소 루트의 `apply_patch.py`, `patch.dat`, `patch_korean.py`, `install.bat`, `revert_patch.py`도 기존 3.10.191.0421용입니다.**
루트 파일을 새 버전에 사용하지 마세요. 버전이 다르면 기존 적용기가 파일을 건너뛰면서 앱을 실행할 수 있으므로 실행창의 원본 검증 결과를 확인해야 합니다.

기존 상세 기록은 [3.10.191.0421 README](versions/3.10.191.0421/README.md)를 참조해 주세요.
