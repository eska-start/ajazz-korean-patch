## 설치

1. 해당 버전의 ZIP을 다운로드하고 새 폴더에 완전히 압축 해제합니다.
2. `install.bat`를 실행하고 관리자 권한을 허용합니다. Python 3가 필요합니다.
3. 완료 문구를 확인하고 AJAZZ의 언어를 **English(영어)**로 선택합니다.

영어 테이블을 한국어로 교체하는 방식입니다. 업데이트 후 프로그램 버전이 바뀌면 해당 버전용 패치가 필요합니다.

## 3.10.200.0420 변경 사항

- 제공된 원본 EXE/DLL에 맞춘 전용 변경분 패치입니다.
- 영어 비압축 테이블 18개와 압축 테이블 3개를 처리합니다.
- 긴 안내문은 의미를 유지해 간결하게 번역했습니다.
- 필수 파일 전체를 사전 검증하며 다른 버전 또는 기존 변경 파일이면 중단합니다.
- 이미 적용된 파일을 구분하고 저장 결과의 SHA256을 검증합니다.
- 백업은 `.ko-backup-3.10.200.0420`으로 별도 보관합니다.
- 플러그인 폴더의 `ko.json`이 존재하는 경우 영어 파일에 적용합니다.
- 바이너리 크기, 압축 해제, JSON 구문, 패치 재구성 SHA256을 확인했습니다. Windows 앱 실행 및 실제 장치 동작은 검증하지 못했습니다.

복원은 관리자 터미널에서 해당 버전 폴더의 `python revert_patch.py`를 실행합니다.

## 기존 3.10.191.0421 패치

기존 파일은 `versions/3.10.191.0421`에 그대로 보존했습니다.

두 플러그인은 함께 설치할 수 있습니다. 각 ZIP을 완전히 압축 해제하고 `install.bat`를 실행합니다. 이전 GIF 버전의 소스와 다운로드 파일은 현재 저장소에서 제거했습니다.

### 단일 GIF 버튼 v0.8.0

사용자 기기에서 이전보다 화질이 나아진 것을 확인했습니다. 144×144 PNG를 전송하고 확대용 프레임을 더 크게 보관합니다. 기존 저해상도 프레임은 **원본 GIF를 다시 선택**해야 개선됩니다. 자동 최적화, 50~300% 배율, 상하·좌우 조절, 브라우저 선택과 폴더·파일 선택창을 포함합니다.

### 전체 분할 GIF v1.2.2

AKP03E **3×2 (6개)** / AKP153 계열 **5×3 (15개)** 배치를 지원합니다. 모든 화면 버튼에 '분할 GIF 버튼'을 배치하고, 어느 버튼에서든 전체 GIF를 한 번 선택합니다. GIF·배속·확대·위치는 기기별로 공유하며 클릭 동작은 버튼별로 설정합니다.

분할 위치와 같은 프레임 배치 전송, 공유 재생·정지, 독립 클릭을 모의 환경에서 확인했습니다. 실제 기기 설치·전송 성능은 추가 확인이 필요합니다. 전체 타일 합계 약 60회/초를 기준으로 6개는 약 10 FPS, 15개는 약 4 FPS가 상한이며 USB 순차 전송에 따른 시간차가 있을 수 있습니다. 기존 일반 버튼의 클릭 기능은 이 액션에서 다시 지정해야 합니다.

#### 버튼 간격 포함 옵션

전체 GIF 설정의 **버튼 간격 포함**을 체크하면 버튼 사이에 가려지는 영역까지 포함해 한 화면으로 배치합니다. 체크 해제 시 기존 분할 방식으로 표시합니다. 기본값은 해제이며, 간격은 버튼 너비 대비 30%를 시작값으로 0~100% 조절할 수 있습니다. 이 설정은 기기별로 공유되고 미리보기에도 반영됩니다. 실제 간격은 기기에 맞춰 조절해 주세요.

#### 페이지별 화면 그룹

각 페이지의 분할 버튼에 같은 **화면 그룹(1~20)**을 지정합니다. 첫 페이지는 그룹 1, 두 번째 페이지는 그룹 2처럼 지정하고 각 그룹에서 GIF를 선택하면 서로 바뀌지 않습니다. 기존 GIF와 설정은 그룹 1에서 이어집니다. 클릭 동작은 버튼별로 유지되며 GIF·간격·확대·배속·재생/정지는 기기와 그룹별로 분리됩니다. 그룹은 페이지 정보를 추측하지 않고 사용자가 직접 지정합니다.

### v1.2.2 분할 순서 복원

복사·이동된 버튼이나 이전 버전에서 남은 수동 조각 번호를 실제 좌표로 초기화합니다. 문자열 좌표를 인식하고 15버튼 화면은 5×3으로 표시합니다. 어느 버튼에서든 **전체 버튼 순서 자동 복원**을 누르면 같은 화면 그룹의 수동 위치만 초기화합니다. **순서 확인 번호 표시**는 위부터 1~5 / 6~10 / 11~15로 표시하며, 해제하면 GIF로 돌아갑니다. GIF와 클릭 동작은 유지됩니다.

검증: `node tests/gif-wall-order.cjs` 통과. 6/15칸, 순서가 뒤섞인 이벤트, 문자 좌표, 복사·이동·기존 수동 설정 초기화, 그룹 격리, 번호 표시와 UI 요소 연결 확인. 실제 AJAZZ 앱 및 기기는 미검증입니다.

### 153 실제 버튼 순서 보정 (v1.2.2)

사용자가 1~15 번호 원본을 표시한 앱 화면에서 `13 10 7 4 1 / 14 11 8 5 2 / 15 12 9 6 3` 순서를 확인했습니다. 이 실측 순열의 역변환을 153의 5×3 분할에 적용합니다. **153 버튼 순서 보정**은 기본 켜짐이며, 표준 행 우선 좌표 호스트에서는 끌 수 있습니다. 단순 가상 좌표 검사만으로 실제 화면 해결을 주장했던 v1.2.1은 이 매핑을 포함하지 않았습니다.
