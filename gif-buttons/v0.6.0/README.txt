AJAZZ AKP03E GIF 버튼 0.6.0

설치/업데이트
1. ZIP을 새 폴더에 완전히 압축 해제합니다.
2. 편집 중인 AJAZZ 설정을 저장하고 install.bat를 실행합니다.
   일반 사용자 권한이며 Python은 필요하지 않습니다.
   AJAZZ가 종료되고 이 플러그인만 교체됩니다. 이전 플러그인 파일은 백업됩니다.
3. AJAZZ를 다시 실행합니다.
4. 기존 GIF 버튼을 선택하거나 오른쪽 GIF 버튼에서
   'GIF 버튼'을 빈 버튼에 배치합니다.

버튼 설정
- GIF 선택: 원하는 GIF 파일을 지정합니다.
- 최대 전송 속도: 2/4/8/12/20/30 FPS, 기본 12 FPS.
- 재생 배속: 0.5/1/1.5/2/3배.
- 버튼을 눌렀을 때: 웹사이트 / 폴더 / 프로그램·파일 / GIF 재생·정지 / 동작 없음.
- 웹사이트 브라우저: Windows 기본 / 네이버 웨일 / Chrome / Edge / Firefox.
  선택한 브라우저가 설치되어 있어야 합니다. 없으면 오류창으로 알려드립니다.
- 폴더 창 방식: 이미 열려 있으면 해당 창 선택 / 항상 새 창으로 열기.
  기존 창 사용은 동일한 전체 경로를 표시하는 탐색기 창을 찾아 복원·활성화합니다.
  없으면 새 창으로 엽니다. 최소화된 창은 복원합니다.
  Windows가 창 활성화를 제한하면 작업 표시줄에서 직접 선택해야 할 수 있습니다.
  Windows 11의 비활성 탭 자동 선택이나 다른 가상 데스크톱 이동은 보장하지 않습니다.
- 주소나 경로 입력 후 변경 사항은 자동으로 저장됩니다.
- '바로 열기'로 지정한 웹사이트·폴더·파일을 열어 볼 수 있습니다.

예시
웹사이트: https://www.naver.com
폴더: C:\Users\사용자이름\Documents
파일: C:\Program Files\프로그램\app.exe
프로그램이나 문서는 전체 경로를 지정합니다. 실행 인자는 현재 지원하지 않습니다.
웹사이트·폴더·파일을 열어도 GIF 재생은 유지됩니다.
GIF 초기화 버튼은 클릭 동작을 유지하며 기본 GIF로만 바꿉니다.
업데이트 전 버튼 설정은 유지됩니다. 이전 4 FPS 설정은 직접 높여 주세요.

성능
단일 버튼에서 12 FPS부터 시작해 20/30 FPS로 올려 주세요.
전체 버튼 합계는 약 60회/초 이하로 전송합니다.
6개를 동시에 쓰면 각 버튼 속도는 약 10 FPS 이하입니다.
실제 GIF 프레임 속도와 장치 전송 처리에 따라 표시 속도가 달라집니다.
GIF 제한: 1MB, 512×512, 200프레임 이하.
사용자 지정 아이콘을 별도로 지정하지 마세요.

폴더·파일 열기
설치 시 현재 Windows 사용자에게 eskaajazzgif URL 연결을 등록합니다.
버튼에서 요청하면 Windows 탐색기 또는 연결 프로그램으로 엽니다.
폴더·파일이 없으면 오류창이 나오며 진단은
%LOCALAPPDATA%\AJAZZGIF\last-open-error.txt에 기록됩니다.
재생·정지 기능만 원하면 이 연결을 사용하지 않습니다.

제거
uninstall.bat를 실행하고 AJAZZ를 다시 실행합니다.
이 플러그인과 해당 URL 연결만 제거합니다.

검증 범위
0.1.0의 실제 AKP03E GIF 재생은 사용자 확인을 받았습니다.
0.6.0의 GIF 디코딩, 재생·정지, 페이지 정리, 웹사이트 요청,
한글 폴더 경로 전달, 파일 요청, 잘못된 주소 거부는 모의 환경에서 검증했습니다.
0.3.0의 열기 동작은 사용자 확인을 받았습니다.
0.6.0의 지정 브라우저 실행 및 열린 폴더 창 활성화는 사용자 Windows 확인이 필요합니다.
이 패키지는 EXE/DLL 및 기기 펌웨어를 변경하지 않습니다.
기존 일반 버튼을 이 GIF 액션으로 바꾸면 클릭 동작을 다시 설정해야 합니다.

0.6.0 수정: 브라우저·폴더·파일 실행 시 PowerShell 창을 숨기는 실행기를 추가했습니다.
install.bat를 실행해야 기존 Windows URL 연결도 새 실행기로 교체됩니다.

0.6.0: 화면에 시험용/테스트 표기를 제거하고 GIF 미리보기, 자동 저장,
동작별 입력란 표시, 접을 수 있는 안내·진단을 추가했습니다.
클릭 설정 변경 시 GIF 재생을 다시 시작하지 않습니다.

0.6.0: 폴더·프로그램·파일 경로 옆 선택 버튼을 추가했습니다.
폴더 선택 또는 파일 선택을 누르면 Windows 선택창이 열립니다.
선택하면 경로가 자동 저장되고, 취소하면 기존 경로를 유지합니다.
수동 경로 입력도 계속 사용할 수 있습니다.
기존 버튼 설정과 브라우저/폴더 창 옵션은 유지됩니다.
실제 Windows 선택창 실행은 사용자 PC 확인이 필요합니다.
