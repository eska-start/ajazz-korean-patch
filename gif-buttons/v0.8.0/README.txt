GIF 버튼 v0.8.0 — 고화질 전송

중요: install.bat로 업데이트한 뒤 원본 GIF를 다시 선택해 주세요.
이전에 저장된 60×60 프레임은 이미 줄어든 상태라 원본 재선택이 필요합니다.

변경
- 전송 이미지를 144×144 PNG로 생성합니다.
- 확대·위치 조절을 위해 프레임을 최대 288×288로 보관합니다.
- JPEG 재압축을 제거했습니다.
- 큰 GIF 자동 축소, 50~300% 배율과 상하·좌우 조절을 지원합니다.
- 설정/웹사이트/폴더/파일 열기 및 선택창 기능은 유지합니다.

설치
ZIP 완전 압축 해제 → install.bat 실행 → AJAZZ 다시 실행.
편집 중인 설정은 먼저 저장해 주세요.
기존 버튼 설정은 유지합니다. 개선된 화질을 위해 원본 GIF만 다시 선택합니다.

주의
기기에 전달하는 이미지가 144×144라는 뜻이며 기기 LCD의 물리 해상도가
144×144로 바뀌는 것은 아닙니다. AJAZZ 본체가 기기에 맞춰 다시 변환할 수 있습니다.
고해상도 프레임 전송으로 이전보다 느려질 수 있습니다. 먼저 12 FPS로 확인해 주세요.
원본 GIF 자체의 낮은 해상도나 색상 제한은 복원할 수 없습니다.
원본 최대 50MB·3000프레임·1677만 픽셀. 저장 데이터가 커지면 프레임 수를 줄입니다.

기능
GIF 선택/미리보기/자동 저장, 최대 30 FPS, 0.5~3배속.
웹사이트·폴더·프로그램·파일 열기, 브라우저 선택.
폴더 기존 창 사용/새 창, Windows 폴더·파일 선택창.
실행창 숨김 및 오류 후 정상 GIF 복원.
제거는 uninstall.bat를 실행합니다.

검증
144×144 PNG 생성, 확대 및 위치 적용, 재생·정지, 오류 복원,
폴더 선택 저장·취소를 모의 환경에서 검사했습니다.
288×288 고화질 변환 및 장기 GIF 전체 재생 시간 유지 검사를 통과했습니다.
실제 장치의 표시 품질과 전송 속도는 사용자 PC 확인이 필요합니다.
