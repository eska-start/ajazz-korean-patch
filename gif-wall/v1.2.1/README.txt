AJAZZ GIF 전체 화면 1.2.1

하나의 GIF를 모든 디스플레이 버튼에 분할해 재생합니다.
AKP03E: 3열 × 2행 (6개) / AKP153 계열: 5열 × 3행 (15개)
기존 단일 GIF 버튼 v0.8.0과 함께 설치할 수 있는 별도 플러그인입니다.

설치
1. ZIP을 완전히 압축 해제합니다.
2. AJAZZ 설정을 저장한 뒤 install.bat를 실행합니다.
3. 오른쪽 'GIF 전체 화면' → '분할 GIF 버튼'을 각 화면 버튼에 배치합니다.
   AKP03E는 6개, AKP153 계열은 15개에 같은 액션을 배치해 주세요.
4. 어느 버튼이든 설정을 열고 '버튼 배치'에서 해당 기기를 선택합니다.
5. GIF 하나를 선택합니다. 같은 기기·화면 그룹의 모든 분할 버튼에 적용됩니다.
   먼저 '기본 전체 GIF로 변경'을 눌러 기본 애니메이션으로 확인해도 됩니다.
6. 버튼별로 웹사이트·폴더·파일 실행 등 클릭 동작을 지정합니다.

설정 공유 범위
전체 GIF, 기기 배치, FPS, 배속, 확대·축소·위치는 해당 기기의 같은 화면 그룹에서 공유합니다.
클릭 동작, URL/경로, 브라우저, 폴더 창 옵션, 분할 위치는 버튼마다 다릅니다.
기기에서 위치를 정상 전달하면 자동으로 해당 조각이 배치됩니다.
다른 조각이 나오면 'GIF에서 보여줄 위치'에서 행/열을 직접 선택해 주세요.
같은 화면 페이지에 배치된 버튼들이 함께 재생합니다.

기존 기능
144×144 PNG 타일 전송, 큰 GIF 자동 최적화, 50~300% 확대·축소,
상하·좌우 조절, 0.5~3배속, GIF 미리보기, 자동 저장.
웹사이트·폴더·프로그램·파일 열기, 브라우저 선택, 기존 폴더 창 사용,
Windows 폴더·파일 선택창, 실행 콘솔 숨김, 오류 후 복원.
재생·정지를 클릭 동작으로 고르면 해당 화면 그룹의 전체 GIF가 함께 멈춥니다.

기존 버튼 기능에 대한 안내
이 플러그인을 배치한 버튼은 클릭 기능을 이 설정 화면에서 다시 지정해야 합니다.
기존 일반 버튼의 아이콘만 자동으로 바꾸는 본체 패치는 아닙니다.
기존 단축키 등 이 플러그인에 없는 동작은 이번 버전에 포함하지 않습니다.
다른 종류의 액션이 배치된 버튼에는 GIF 조각을 보낼 수 없습니다.

성능과 한계
한 번의 갱신에 모든 타일을 같은 원본 프레임으로 묶어 보냅니다.
USB 전송은 순차 처리되므로 실제 화면의 완전한 동시 갱신은 보장하지 않습니다.
전체 타일 합계 전송량 약 60회/초 기준:
6개 사용 시 최대 약 10 FPS, 15개 사용 시 최대 약 4 FPS로 제한합니다.
설정에서 더 높은 FPS를 골라도 전체 버튼 수에 따라 자동 제한됩니다.
버튼 간격 포함 체크 시 물리 간격을 반영합니다. 기본값은 체크 해제로 기존 표시를 유지합니다.
간격 기본값은 버튼 너비의 30%이며 0~100%로 조절할 수 있습니다.
체크 상태와 간격은 같은 기기·화면 그룹의 모든 분할 버튼에 함께 적용됩니다.
간격이 바뀌어도 GIF를 다시 선택할 필요가 없습니다.
원본 GIF 최대 50MB, 3000프레임, 1677만 픽셀.
원본 비율을 유지하므로 화면 비율과 다르면 여백이 생깁니다.
큰 GIF의 프레임 저장량을 줄이는 과정에서 일부 움직임이 생략될 수 있습니다.

검증
6개와 15개 타일의 분할 위치를 픽셀로 확인했습니다.
같은 프레임 배치 전송, 공유 재생·정지, 독립 클릭, 페이지 이탈 정리를 검사했습니다.
전체 GIF는 전역 설정에 한 번 저장하고 버튼별 설정에는 복제하지 않습니다.
실제 AKP03E/AKP153 설치, 전역 설정 전달, USB 성능은 사용자 기기 확인이 필요합니다.

제거
uninstall.bat 실행 후 AJAZZ를 다시 실행합니다.
기존 단일 GIF 버튼 플러그인은 그대로 유지합니다.

버튼 간격 보정 사용법
어느 분할 버튼에서든 설정을 열고 버튼 간격 포함을 체크합니다.
미리보기에도 같은 간격을 표시합니다. 실제 기기와 맞지 않으면 간격 슬라이더를 조절합니다.
해제하면 기존 분할 방식으로 즉시 돌아갑니다.

페이지마다 다른 GIF 사용
1. 첫 페이지의 모든 분할 버튼을 화면 그룹 1로 지정합니다. 기존 설정은 그룹 1에서 유지됩니다.
2. 다른 페이지의 모든 분할 버튼을 화면 그룹 2로 지정한 뒤 GIF를 선택합니다.
3. 이후 페이지는 그룹 3~20을 사용합니다. 서로 다른 기기도 독립적으로 저장됩니다.
그룹을 바꾸면 그 그룹의 저장된 GIF를 불러옵니다. 새 그룹은 GIF를 먼저 선택해야 합니다.
다른 페이지도 같은 그룹을 지정하면 의도적으로 같은 GIF를 공유합니다.
GIF·간격·배속·위치·재생/정지가 그룹별로 분리됩니다. 버튼 클릭 동작은 유지됩니다.

1.2.1 버튼 순서 수정
- 복사·이동·이전 버전의 수동 조각 번호는 실제 위치에 맞춰 자동 초기화합니다.
- 숫자 문자열 좌표를 인식하고, 15버튼 화면 좌표에서 5×3을 자동 인식합니다.
- 전체 버튼 순서 자동 복원: 현재 화면 그룹의 수동 조각 지정만 초기화합니다.
- 순서 확인 번호 표시: 위부터 1~5 / 6~10 / 11~15를 확인하고 해제합니다.
- GIF·간격·배율·화면 그룹·클릭 동작은 유지합니다.
